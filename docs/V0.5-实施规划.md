# V0.5 实施规划 —— 可信测量闭环：从「实验方法审计」到数据可靠性门禁

> 版本目标：任何测量数据进入系统前先过**方法学门禁**；只有 `verified` 数据才能流向
> QC 指标、监控趋势、ΔE 分量报告与 V0.4 的补偿模型。历史参考实测样本只作为
> **格式模板与方法教训样本**，不作为真值来源。

## 1. 背景与动机

三份印前测量方法学参考案例（颜色测量与计算 / 胶印色彩管理工程实践 / 印刷材料综合实践）
提供了完整的实验数据链：30 个 CGATS 分光测量导出、油墨四指标（色强度/色相误差/
灰度/色效率）、Murray–Davies 网点面积率与 TVI、GATF 色轮、纽介堡方程对照、
ΔE 分量计算。**数据量可观，但数据可靠性缺失**：

- 单次测量、无复测记录；
- 仪器校准状态未记录（无校准时间、无白板/黑筒信息）；
- 测量条件（光源/观察者/条件类别/背衬/孔径）几乎未声明；
- MeasureTool → txt → Excel → 报告表格的人工转录链，已发现多处行错位与复制粘贴错误；
- 同一表内换算口径漂移（明度归一化基准前后不一致，数值无法复算）。

因此 V0.5 不做「把历史实验数据搬进产品」，而是把**实验方法闭环**做成产品能力：
先审计方法（本章），再建可靠性管线（M1），让后续所有功能只消费可信数据。

## 2. 实验方法闭环审计（七要素）

对三份报告的实验方法逐项审计。七要素：仪器与校准、测量条件、样品制备、
重复测量与一致性、数据转录链、计算方法交叉验证、异常处理。

### 2.1 报告甲：颜色测量与计算（颜色科学与技术）

| 要素 | 报告现状 | 审计结论 |
|---|---|---|
| 仪器与校准 | X-Rite 分光光度计/色度计；无校准记录 | ⚠ 无校准链，测量结果不可溯源 |
| 测量条件 | 未声明 M0/M1/M2、背衬、孔径；仅说明 D65/2° 用于**计算** | ⚠ 计算口径明确、测量口径缺失 |
| 样品制备 | C100/M100/Y100 及三组叠印实地、8 色域色块、CMY 梯尺 | ✓ 覆盖面好，块序清晰 |
| 重复测量 | 无复测；纸白 Lab 恰为 (100,0,0) 说明按纸白归一 | ⚠ 单次测量；归一化基准未显式声明 |
| 转录链 | MeasureTool 导出 txt → Excel 公式计算 → 报告表格 | ⚠ 三级人工转录 |
| 计算交叉验证 | **亮点**：预加权函数 vs 重建加权函数两法计算 XYZ 互核；计算值 vs 仪器值对比 | ✓ 方法二校验方法一，ΔX 约 5%（舍入+方法差） |
| 异常处理 | 纸张发黄、叠印黑短波反射率异常等仅口头归因 | ⚠ 无量化异常判定 |

正面证据（可复算）：Murray–Davies C60：α=(1−10⁻⁰·⁵¹)/(1−10⁻¹·⁴⁹)=0.714 ✓；
油墨四指标 C100（DH=1.55, DM=0.43, DL=0.17）→ 色偏 0.188≈0.19 ✓、色灰 0.110 ✓、
色效率 0.806≈0.81 ✓ —— 公式实现可按此对拍。

反面证据（可靠性探针命中）：
- 纸白 W 行 XYZ(107.85, 98.36, 34.32) → L\*≡100.00、a\*≡0、b\*≡0：以纸白归一，
  但同报告设备测量表内部分行按绝对 Y 计算明度，**换算关系对不上，数值无法复算**；
- 纽介堡 C20Y20 计算值 Z=70.82 vs 实测 45.83（偏差 +55%）：误差归因正确
  （墨层相互作用/网点变形/基材），但**基础数据未过任何校验就直接进入方程**。

### 2.2 报告乙：胶印色彩管理工程实践

| 要素 | 报告现状 | 审计结论 |
|---|---|---|
| 仪器与校准 | 无实体测量——全程 Photoshop ICC 软件转换 | ⚠ 「数据」为软件仿真，非测量 |
| 测量条件 | 声明再现意图（绝对比色）并「锁定纸张白场」 | ✓ 意图与参考白声明清楚 |
| 样品制备 | RGB/CMYK 标准色靶图像 | ✓ |
| 重复测量 | 不适用（无测量环节） | — |
| 转录链 | Photoshop 信息面板截图 → 报告表格 | ⚠ 屏幕读数转录 |
| 计算交叉验证 | ΔL/Δa/Δb → ΔE\*ab 手算，可复算（如 Δ(0,4,3)→5.00 ✓） | ✓ |
| 异常处理 | 高色差归因于色域裁切/叠印误差，逻辑自洽 | ✓ 定性分析到位 |

审计结论：这份报告是**纯软件闭环**（等价于本产品 ICC 转换功能），其价值在
「绝对比色 + 纸白锁定」的口径声明示范，而非数据本身。

### 2.3 报告丙：印刷材料综合实践

| 要素 | 报告现状 | 审计结论 |
|---|---|---|
| 仪器与校准 | 别克平滑度仪、多角度光泽度仪、白度仪、PPS、K&N、抗张机、IGT AIC2-5、Xrite530 | ⚠ 仪器清单完整，校准记录缺失 |
| 测量条件 | IGT 打样参数明确（625N、0.2m/s，按纸种 0.12/0.24/0.36ml 上墨）；白度 D65/10° | ✓ 打样条件可复现 |
| 样品制备 | 三纸种裁切规格明确（10×10 / 1.5×10 / 7.5×10cm），正反面区分 | ✓ 制备规范（亮点） |
| 重复测量 | 白度/抗张「各三次取平均」；其余单次 | △ 部分复测，未做一致性判定 |
| 转录链 | 密度仪 → 手工表格 | ⚠ 已见复制粘贴事故 |
| 计算交叉验证 | GATF 四指标 + 色轮；平行板 vs 锥板黏度计双仪器互核（剪切速率差异归因） | ✓ 双仪器对照意识好 |
| 异常处理 | 「新闻纸样条色彩重复性不佳 → 排查后确认纸张吸收性不均 → 调整流程」 | ✓ 有真实闭环案例 |

反面证据（可靠性探针命中）：
- **跨行复制粘贴**：铜版纸表 Y 色相误差 9.01% 与新闻纸表 Y 色相误差 9.01% 完全相同，
  概率极低，属典型转录事故；
- **跨表判定矛盾**：同一样张在平滑度/光泽度表判为 A 类，在白度表判为 B 类，
  K&N 值又指向 C 类——单指标异常未做交叉校验，最终靠综合判定「人肉仲裁」；
- **数据空洞**：表观黏度表出现整行 0.00（负数被置空？缺测？），无口径说明。

### 2.4 审计总评

| 维度 | 评价 |
|---|---|
| 实验设计意识 | 强（对照、双仪器互核、变量控制、条件声明都有示范） |
| 数据可靠性基建 | 弱（无复测门禁、无校准溯源、无自动校验、转录链断裂） |
| 对产品的启示 | **把「报告里靠人肉做对的事」固化成代码，把「报告里翻车的事」变成自动拦截项** |

## 3. 可靠性风险清单（典型问题现状 → 工业实践要求 → 产品对策）

| # | 典型问题现状 | 工业实践要求（ISO 12647-2 / 13660 / GATF 精神） | 产品对策（V0.5 落点） |
|---|---|---|---|
| R1 | 校准状态未记录 | 测量系统受控，校准可追溯（时间/白板/仪器标识） | M1 会话登记 `instrument` + `calibrated_at` 必填 |
| R2 | 测量条件（M0/M1/M2、背衬、孔径）未声明 | 条件声明是数据可比性的前提 | M1 会话登记 `condition`/`backing`；不同条件数据显式标注不可比 |
| R3 | 单次测量无复测 | 重复性门限（ΔE 复测差 ≤ 0.4 量级） | M1 复测一致性规则；M3 样张**双点重复布局**从源头保证复测可行 |
| R4 | 三级人工转录（txt→Excel→报告） | 采集直连、零转录 | M1 CGATS.17 直读解析器，raw 文件即最终记录 |
| R5 | 光谱↔色度口径漂移、归一化基准不一致 | CIE 15 明确光源/观察者/归一化 | M1 光谱积分交叉验证（复算 Lab vs 报告 Lab，ΔE>1.5 → rejected） |
| R6 | 密度/网点异常值放行（负值、>2.5、0.00 空洞、通道错位） | 物理量程门限 | M1 密度合理性规则 + M2 公式复算对拍 |
| R7 | 同批离群靠事后人眼 | SPC 3σ 批次控制 | M1 同批 3σ 离群规则；复用 V0.4 监控漂移告警 |
| R8 | 基础数据随条件失效无感知（纽介堡「印刷参数改变后必须重测」思考题） | 条件变更即重标定 | 已有：ICC sha 变更→补偿失效；新增：M4 补偿累积**只接受 verified 测量** |

## 4. 方法闭环定义（V0.5 产品方法论）

```
测前登记 ──► 校准确认 ──► 测量 ──► 复测一致性 ──► 交叉校验 ──► 可信度分级 ──► 分级数据流向
   │            │           │           │              │              │              │
 会话表单    instrument+  样张(M3)    同标签≥2次     光谱↔Lab复算    verified      verified→QC指标/趋势/
 (instrument  calibrated  双点重复    ΔE≤0.4        +纸白校验      │warning      ΔE分量/补偿模型
  /condition/  _at 必填)   布局        (M1规则1)     +密度合理性    │rejected      warning→仅展示,不进
  backing)                              3σ离群(M1规则5) (M1规则2/3/4) ─┘             指标与补偿
                                                                     rejected→可查不可用
```

七步与七要素一一对应：R1→测前登记/校准确认，R3→复测一致性，R4/R5/R6→交叉校验，
分级与流向是闭环的**出口**——任何下游（M2 指标、M4 分量、V0.4 补偿）只认 verified。

## 5. 里程碑与验收

### M1：测量导入 + 数据可靠性管线（核心基建）

| 交付物 | 说明 |
|---|---|
| `app/services/cgats.py` | CGATS.17 文本解析（BEGIN_DATA/END_DATA、字段行、# 注释、编码容错）；字段 LAB_L/A/B、SPECTRAL_380-730、CMYK_D、RGB_R/G/B；以常见仪器导出为**格式模板**（测试断言结构可解析，不做真值断言；fixtures 用合成数据+人工扰动副本） |
| `app/services/measurement_qa.py` | 五条规则 → `reliability: verified|warning|rejected` + `reasons[]`：①复测一致性（同标签≥2 次，ΔE 复测差≤0.4，可调常量）②纸白校验（vs 工艺 ICC 纸白 Lab）③光谱↔Lab 交叉验证（SPECTRAL 380-730 按 D50/2° 积分 vs 报告 Lab，>1.5 → rejected）④密度合理性（负值/>2.5/通道错位）⑤同批 3σ 离群 |
| `data/measurements.json` | JsonStore 会话模型：`{instrument, condition(M0/M1/M2), calibrated_at, backing, notes}` + records |
| API | `POST /api/qc/measurements/import`（raw txt + 会话参数）、`GET /api/qc/measurements`、`DELETE /{id}` |
| UI | 监控页「测量数据」卡：批量导入向导（会话登记 → 逐文件 verified/warning/rejected 徽标 + 原因），rejected 可查不可用 |

验收：解析器对格式模板全量可解析；五规则正反用例各 ≥1；光谱-Lab 不一致样例必须 rejected。

### M2：密度与油墨质量面板（只消费 verified）

| 交付物 | 说明 |
|---|---|
| `app/services/density.py` | 色强度 DH；色相误差 (M−L)/(H−L)；灰度 L/H；色效率 1−(L+M)/(2H)（附行业别名 色纯度=(H−L)/H）；Murray–Davies α=(1−10^−Dt)/(1−10^Ds)；TVI=α−名义网点率 |
| API | `POST /api/qc/ink-quality`（会话/记录 id → 四指标 + TVI 曲线） |
| UI | 监控页「印刷 QC」卡：四指标 + TVI canvas 曲线 + GATF 色轮（八方位扇形图）；**无 verified 数据时显示方法要求占位文案**（教育：何为可信数据） |

验收：四指标/Murray–Davies 与报告可复算数值对拍（C100 组、C60 组）；
rejected/warning 数据被排除的用例成立。

### M3：测试样张生成器（方法标准化的载体）

| 交付物 | 说明 |
|---|---|
| `app/services/testform.py` | Pillow CMYK 栅格样张：实地/叠印条、每色 0→100 十一级梯尺、灰平衡格、**每个测量目标双点重复布局**（服务 M1 复测一致性）、角线+目标编号；输出 TIFF + PDF（pypdf 组页，零新依赖）；设备值直出（测设备自身表现，不做 ICC 转换） |
| API | `POST /api/qc/testform?process_id=` |
| 入口 | 工艺详情「生成验证样张」按钮 |

验收：生成的样张经预检可读；双点标签可配对（同 label 两坐标）；PDF 页数/尺寸正确。

### M4：ΔE 分量分解 + 补偿门禁

| 交付物 | 说明 |
|---|---|
| `core.py` | `delta_e_components(lab1, lab2)` → {dL, da, db, dC, dh, dE76}（ΔE2000 主口径不变） |
| verify 响应/结果卡 | 分量展示 + 解读文案（ΔL 偏亮暗 / ΔC 饱和差 / Δh 色相偏） |
| 补偿门禁 | `compensation.accumulate` 仅接受关联测量 reliability=verified 的验证；warning/rejected 验证照常修正配方但不沉淀 |

验收：分量手算断言；未带 verified 测量的 verify 不改变补偿模型状态（n 不变）。
