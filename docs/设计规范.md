# 色彩工坊 · UI 设计规范（iOS 扁平风）

> 本文档是前端的设计令牌与组件速查，修改样式前先读这里。
> 设计原则：**扁平、克制、有流程感**——参考苹果 iOS 分组列表与大标题范式，
> 拒绝重投影与新拟态；色彩数据本身是页面的视觉主角。
>
> V0.10 的工艺护照、光谱曲线、配方语义与签样护照门禁已实现；
> 本文记录现行组件口径，未完成的增强项集中列在 7.9。

## 1. 设计令牌（`css/app.css` `:root`）

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#F2F2F7` | `#000000` | 页面背景（iOS grouped） |
| `--card` | `#FFFFFF` | `#1C1C1E` | 卡片 |
| `--fill` / `--fill-2` | 6%/14% 灰 | 18%/28% 灰 | 内嵌填充、次级按钮 |
| `--label` / `--label-2` / `--label-3` | `#1C1C1E` / `#6C6C70` / `#AEAEB2` | 白 / 62% 白 / 36% 白 | 主/次/三级文字 |
| `--separator` | 12% 灰 hairline | 55% 灰 hairline | 1px 分隔线 |
| `--accent` | `#007AFF` | `#0A84FF` | 主色/链接/选中 |
| `--green` / `--orange` / `--red` | `#34C759` / `#FF9500` / `#FF3B30` | 对应亮色变体 | 达标/警告/超差 |

- 字体：`-apple-system, "PingFang SC", "Segoe UI", system-ui`；数字/配方用 `--mono`。
- 圆角：卡片 16 / 按钮 10 / 小元件 8；8pt 栅格。
- 阴影：卡片仅 `0 1px 2px` 微阴影，弹层 `--shadow-pop`；**禁止大面积投影**。
- 主题：跟随系统 + 手动切换（localStorage `theme`），`html[data-theme="dark"]` 切换令牌。

| 组件 | 类名 | 要点 |

| 按钮 | `.btn`（默认/secondary/ghost/danger/sm/block） | 高 40（sm 32），按下 `scale(.97)` |
| 分段控件 | `.seg` | 灰底 pill + 白色滑块，用于意图/工具切换 |
| 徽标 | `.badge-green/-orange/-red/-blue/-gray` | 状态语义：达标/可用/超差 |
| 分组列表 | `.group-row` | iOS inset list，行间 hairline |
| 色块 | `.swatch` / `.swatch-sm` | Lab→hex（Bradford 适应），圆角 10 |
| 配方芯片 | `.recipe-chip` | 通道色（C 青/M 紫/Y 黄/K 灰）+ 数值 + 进度条 |
| 轨迹图 | `sparkline()` | SVG 折线 + 容差虚线，达标绿/超差橙 |
| 阶段流水线 | `.step`（done/current/locked） | 纵向轨道 + 状态圆点，锁定阶段半透明虚线卡 |
| 折叠披露 | `.disclosure` | 渐进式披露载体，chevron 旋转 |
| 空状态 | `.empty` | 图标 + 标题 + 引导动作按钮 |
| toast | `toast()` | 顶部浮出，2.6s 自动消失 |
| 模态 | `openModal()` | 20px 圆角弹层，遮罩点击关闭 |
| 拖放上传 | `.dropzone` | 虚线边，hover/拖入变 accent |
| CIE 图 | `drawCie()` | Canvas DPR 校准，网格 + 光谱轨迹 + 多边形/点集 |
| 护照/光谱状态 | `.badge-*` + 图标/文字 | 不得只用颜色；有效/待补证/已变/无效/不可用均有文本 |
| 护照详情 | `openModal()`，宽 `min(700px, 100%)` | 证据/警告/免责声明；焦点圈闭，ESC 关闭 |
| 双光谱曲线 | `openModal()` + Canvas，宽 `min(760px, 100%)` | DPR 校准、实际波长范围、基线 1.0、文字图例 + 数据表 |

## 4. 渐进式披露层级

- **L1 默认一屏**：配方预测 = 选工艺 → 填 LAB → 预测；CSV 批量粘贴藏在折叠区。
- **L2 结果卡展开**：swatch 对比 / 配方芯片 / 迭代轨迹默认可见；实测验证经模态提交。
- **L3 专业工具**：正查、色域对比、转换器收纳在工具箱；旧 V0.1 端点仅作数据源。

## 5. 流程感（前后依赖可视化）

印前转换用 PipelineStepper：阶段未完成时下一阶段呈 `locked`（半透明 + 虚线卡），
完成打勾绿色、当前阶段 accent 光圈。**任何流程页面都应有明确的"第 N 步"感，
禁止把有依赖的功能做成并列卡片**——这是 v0.2 重构的核心 UX 决策。

## 6. 动效准则

- 位移用 `transform`（GPU 合成），颜色/背景过渡 0.15–0.25s ease。
- 出现动画统一 `pop-in / fade-in / toast-in`（带轻微回弹），消失 0.25s。
- Canvas 一律按 `devicePixelRatio` 校准，避免高分屏模糊。

## 7. V0.10 工艺护照与光谱风险（已实现）

### 7.1 工艺护照卡

位置：工艺详情页，靠近现有补偿模型/校准历史/签样卡，作为“证据版本”入口。

| 区域 | 内容 |
|---|---|
| 标题行 | “工艺护照” + 动态状态徽标 + 当前版本（如 `v3`） |
| 摘要行 | `hash` 前缀（等宽字体）、生成时间、快照幂等说明 |
| 证据覆盖 | 可信测量条数、校准轮次、配方条数、光谱块数、光谱最高风险 |
| 风险提示 | 状态原因 + 结构化警告；卡片预览最多 3 条，完整内容进详情模态 |
| 操作 | **生成/刷新**（主按钮）、**下载 JSON**、**下载 MD**、**查看详情** |

- 未生成时显示空状态“未生成工艺护照”，说明能覆盖哪些证据；只保留“生成”一个主动作，
  不显示伪造的 hash、版本或 `valid`。
- `invalid/stale/incomplete` 使用不同状态文案与图标；危险操作（错误状态下继续签样）
  不在前端提供“忽略”入口。

### 7.2 护照详情模态

- 当前实现为 `openModal()` 模态，桌面宽约 700px，375px 下占满宽度；不是右侧抽屉。
- 顶部：状态徽标 + 版本 + 生成时间；正文使用 `dl.kv` 展示 hash、测量条件、ICC、
  补偿模型、校准轮次、可信测量、配方历史、光谱覆盖与最高风险。
- 状态原因与警告分别成组展示；缺失项显示“未记录”或“无可用光谱”，不以空值冒充。
- 常显光谱免责声明；关闭按钮位于底部，关闭后焦点回到“查看详情”。
- 版本历史已有 `/passport/versions` API，但**当前 UI 未提供独立版本历史列表**，
  列为后续改进（见 7.9）。

### 7.3 状态色与风险色

沿用现有 iOS 语义色，不新增高饱和色：

| 语义 | 色令牌 | 文案示例 | 图标 |
|---|---|---|---|
| 护照有效 | `--green` | 有效 | checkmark |
| 证据不足 | `--orange` | 证据不完整 | 感叹号 |
| 证据已变 | `--red` | 已失效（需刷新） | xmark |
| 护照无效 | `--red` | 无效 | xmark |
| 未生成 | `--label-3` / gray | 未生成 | 文档占位 |
| 光谱低风险 | `--green` | 低风险 | checkmark |
| 光谱中风险 | `--orange` | 中风险 | 感叹号 |
| 光谱高风险 | `--red` | 高风险 | xmark |
| 光谱不可用 | gray | 无可比 | gray badge |

- `stale` 与 `invalid` 当前同为红色/xmark，必须靠“已失效”与“无效”不同文案区分；
  后续可补不同图标。
- 徽标文字与底色对比度目标 ≥ 4.5:1；禁止浅红字配浅红底，本版未做专项对比度测量。
- 风险数值（max ΔE）与等级并列；等级不能替代数值，数值也不能没有文字等级。

### 7.4 光谱 / 同色异谱卡

位置：监控页 QC 指标/趋势附近，新增“光谱 / 同色异谱”卡。

- 两个会话选择器（主 / 对比），从测量会话中选择；少于两个会话时仍可选择，
  点击比对会提示“请选择两个不同的测量会话”。
- 选择后按 `patch label` 匹配；卡内展示：
  - 匹配 patch 数 / 可比较会话数；
  - 四光源中的**最大 ΔE00、最差光源、风险等级**；
  - top 差异 patch 列表（标签、ΔE00、最差光源、风险），接口取 `top_n=12`，界面展示前 10 条；
  - 每行“曲线”按钮打开双光谱模态。
- 常显免责声明：“工程同色异谱风险指标，不等同 CIE 15 特殊同色异谱指数 MI”。
  该声明不得只放在 tooltip 或折叠区。
- 无光谱：显示 `available=false` 的空状态“无可用光谱数据”，提供导入入口；不画空曲线，
  不显示伪造 ΔE。
- 坏光谱/波长越界/反射率异常：能算的项继续展示并标警告；不能算的项标“不可用”，
  不以 0 填充或平滑插值。

### 7.5 双光谱曲线模态

- 当前桌面宽 `min(760px, 100%)`；头部显示 patch label 与免责声明。
- Canvas 按 DPR 校准；X 轴使用实际波长范围（不强行统一网格），Y 轴按数据自适应并
  保留 1.0 参考线；OBA 反射率 >1 必须显示在曲线上，不得截断到 1.0。
- 两条曲线当前用 accent/purple 颜色 + 文字图例区分；**线型/标记等非颜色编码尚未实现**，
  数据表提供替代读取，列为后续改进。
- 图下提供各光源表：光源、两条曲线的 Lab、ΔE00、风险；最差光源以数值与风险徽标展示。
- 模态内独立滚动；关闭后焦点回到触发按钮；不得叠加第二层模态。

### 7.6 配方语义与签样护照

- 配方结果卡标题与导出统一使用**“分色值（设备值）”**；副文案明确
  “设备通道百分比，用于该工艺输出，不是实物调墨配方”。
- 禁止单独使用“配方”指代设备值；调墨配方未实现时不得出现“生成调墨配方”按钮。
- “导出配方单”支持 JSON/Markdown；按钮旁提示设备值语义，导出文件名为
  `recipe-<recipe_id>.json/.md`。
- 签样创建模态增加可选“关联工艺护照”：展示状态、版本、hash 前缀；状态为
  `invalid/stale/incomplete` 时如实展示但置灰，标注“不可关联”，服务端同样返回 422。
- 门禁失败：`passport_changed` 提示签样绑定的护照已变化；`passport_stale/invalid/incomplete`
  显示当前护照状态与原因。均并列签样 hash 与当前 hash 前缀，不提供“忽略并放行”。
  approved/locked 签样旁提供“重新签样”入口。legacy 签样无护照引用时不显示。
- `passport_*` 门禁失败尚未使用 `role=alert`/`aria-live`，列为后续无障碍改进。

### 7.7 375px 适配

- 护照卡的操作按钮允许换行，主操作在窄屏可占满整行；不得缩小到 44px 以下。
- 护照详情/光谱模态占满宽度，内容区滚动；避免横向溢出。
- 护照 hash 使用 `overflow-wrap:anywhere`，优先换行而非省略关键字符；
  版本、状态和 hash 前缀必须同屏可读。
- 光谱卡两个会话选择器与操作按钮纵向堆叠；top 差异当前保留紧凑表格，
  375px 下以截图验收可读性，纵向卡片化为后续优化。
- 曲线图高度 ≥220px；各光源表横向滚动时固定首列，或改为逐光源纵向卡片；
  不得把字号压到 12px 以下。
- 所有主要触控目标以 ≥44×44px 为目标；warning 行与操作按钮不重叠，本版未做专项触控测量。

### 7.8 无障碍与文案

- 状态/风险徽标同时含文字与图标，视觉上不只靠颜色；未单独设置 `aria-label`。
- 模态有 `role="dialog"`/`aria-modal="true"`、焦点圈闭、ESC 关闭、关闭后焦点恢复；
  尚未关联 `aria-labelledby`，也未把背景设为 `inert`。
- `passport_changed` / `passport_stale` / `passport_invalid` / `passport_incomplete`
  门禁失败尚未使用 `role=alert`/`aria-live`，由页面内文本承载。
- 光谱曲线旁提供各光源 Lab/ΔE00 表格；Canvas 本身尚无 `aria-label`，
  屏幕阅读器主要依赖表格读取。
- 支持键盘操作；**完整 200% 缩放与屏幕阅读器审计未完成**，列为后续验收。
- 尊重 `prefers-reduced-motion`：模态不做大幅位移，曲线不做绘制动画；
  动效时长不超过 0.25s。
- 文案统一：“工艺护照”“分色值（设备值）”“工程同色异谱风险”“CIE F11”；
- 禁止文案：“AI 认证”“CIE 15 MI 已通过”“PDF/X 认证”“调墨配方已生成”。
