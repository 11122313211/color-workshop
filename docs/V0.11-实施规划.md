# 色彩工坊 V0.11：工艺生命周期完整性 · 护照历史 · 可用性修复

## Summary
- 基线：V0.10 已提交，`233 passed`，服务版本 `0.10.0`；本版不改配方反查、光谱阈值或护照 hash 语义。
- 3 周、3 个一周 Sprint：S1 归档生命周期与依赖门禁；S2 完整性审计/修复与数据维护 UI；S3 护照版本历史、a11y、跨平台 E2E 与文档。
- 删除改为**归档优先**：默认不丢证据；永久清理只允许对已归档工艺，测量/签样/评价保留为审计证据。

## Implementation Changes

### 1. 归档生命周期
- `ProcessStore` 增加可选 `archived_at`、`archive_reason`、`archived_by`；旧数据默认 active。保留 `ProcessStore.delete()` 作为内部硬删除，API 默认走归档。
- `GET /api/processes?include_archived=0|1`，默认只返回 active；`DELETE /api/processes/{pid}` 改为归档；新增 `POST /archive`、`POST /restore`、`DELETE /permanent?confirm=<pid>`（仅 archived）。
- 归档工艺只读：预测/验证、测量导入、评价创建、签样创建、护照生成、ICC 替换、文件转换/PDF-X、工艺编辑全部返回 409 `PROCESS_ARCHIVED`；读取、历史、护照版本仍可访问。
- 新增 `GET /api/processes/{pid}/dependencies`：recipes、compensation、calibrations、passports、measurement_sessions、evaluations、signoffs 分状态计数与 blockers。
- 永久清理：删除 process + ICC、recipes、compensation、calibrations、passports；measurements/evaluations 解绑保留（`detached_from_process`、`detached_at`）；signoffs 不删除，标记 `orphaned_at`、`orphan_reason`；响应返回清理/解绑/标记计数。
- `signoffs/gate` 对 archived 返回 `process_archived`；`release-manifest` 返回 409。UI 增加“显示已归档”、归档徽标、恢复/永久删除按钮。

### 2. 完整性审计与修复
- 新增 `app/services/integrity.py`：扫描 active/archived、孤儿 recipes/compensations/calibrations/passports、孤儿 measurement sessions/evaluations、孤儿 signoffs、缺失 ICC、未引用 ICC 文件。
- 修复策略：孤儿 measurement/evaluation 解绑保留；孤儿 signoff 标记 orphaned、不删除；孤儿派生记录删除；未引用 ICC 移至 `data/orphaned_icc/` 隔离。默认 `dry_run=true`，显式 apply 才写入。
- API：`GET /api/integrity/report`、`POST /api/integrity/repair`（body `{dry_run, actions}`）。
- CLI：`scripts/audit_data.py --dry-run|--apply`。
- UI：工具箱新增“数据维护”页，显示报告、修复预览、应用修复、下载 JSON。
- 当前数据预期报告：2 条孤儿配方（`504d51b2dc3e`）、1 个孤儿测量会话（`sess_757b195b0f33`）、1 个孤儿签样（`sg_fbefe1266414`）；修复后删除 2 条派生配方、解绑会话、标记签样。

### 3. 护照版本历史
- `GET /api/processes/{pid}/passport/versions` 增加 `is_latest`、`referenced_by_signoffs`（id/state/title）、`referenced_count`。
- `SignoffStore` 新增 `references_for_passport(process_id, passport_id, passport_hash)`，用于判断版本是否被签样引用。
- 工艺护照卡新增“版本历史”按钮；模态表格展示 v/status/hash/generated_at/warnings/签样引用；点击版本打开只读详情；归档工艺仍可只读查看。
- 不修改护照 hash、版本号、快照不可变与 50 版上限语义。

### 4. 可用性 / a11y
- `openModal`：自动从首个标题生成 `aria-labelledby`，无标题时用 `aria-label`；打开时给 `.app` 及其他 modal mask 加 `inert`/`aria-hidden`，关闭恢复；保留焦点圈闭与焦点还原。
- `passport_changed` 门禁块增加 `role="alert"`、`aria-live="assertive"`。
- 光谱曲线：A 实线 + 圆点，B 虚线 + 方点；Canvas 加 `role="img"`、摘要 `aria-label`、`aria-describedby` 指向数据表；375px 顶部差异表改为纵向卡片。
- 新增 `scripts/shoot_v11.py`：护照历史、数据维护、光谱曲线 200% CSS zoom、375px、暗色截图；新增 `docs/V0.11-验收.md` 键盘路径清单（Tab/Shift+Tab/Esc/焦点还原/归档/修复确认）。

### 5. 跨平台与文档
- `scripts/e2e_http.py` 去掉 Windows `RSWOP.icm` / `JapanColor2001Coated.icc` 依赖，统一使用 `tests/fixtures/icc/testbed_cmyk.icc`；ICC 替换用同文件 header 日期字节变体（保持合法、sha 不同）。
- 更新 README、PRD、印前标准 7 步评判、设计规范；新增 `docs/V0.11-实施规划.md`、`docs/V0.11-实施记录.md`；版本号 `0.11.0`。
- 不做强制数据迁移：归档字段缺省即 active；执行后先跑 `scripts/audit_data.py --dry-run`，确认后再 apply。

## Public APIs & Types
- `GET /api/processes?include_archived=0|1`
- `POST /api/processes/{pid}/archive`（body `{reason, actor}`）
- `POST /api/processes/{pid}/restore`
- `DELETE /api/processes/{pid}`（归档）
- `DELETE /api/processes/{pid}/permanent?confirm=<pid>`（仅 archived）
- `GET /api/processes/{pid}/dependencies`
- `GET /api/integrity/report`
- `POST /api/integrity/repair`（body `{dry_run, actions}`）
- `GET /api/processes/{pid}/passport/versions`（新增引用字段）
- 类型：`ProcessOut.archived_*`、`DependencyReport`、`IntegrityReport`、`IntegrityRepairRequest/Result`、`PassportVersionSummary`、`MeasurementSession.detached_*`、`Signoff.orphaned_*`、`Evaluation.detached_*`。
- 兼容规则：新增字段可选；旧数据默认 active/未孤儿；唯一有意的行为变更：`DELETE /api/processes/{pid}` 从硬删除改为归档，永久删除走 `/permanent`。
