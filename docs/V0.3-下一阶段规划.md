# V0.3 下一阶段规划 —— ICC 模块视觉升级 + 功能完善 + 体验打磨

> 版本：V0.3（规划基线 V0.2） · 定稿日期 2026-11-15
> 规划方法：行业前沿查证 / 产品设计 / 编码可行性 / 测试策略 四路调研交叉验证后定稿。

## 1. 版本定位

V0.2 已完成旗舰链路（LAB→CMYK 反查、实测验证闭环、工艺库、印前转换）。V0.3 不扩新业务域，
聚焦三件事：

1. **ICC 模块（工艺库）视觉升级** —— 把「能用」变成「专业好看」：凸包色域、L\* 明度着色、
   伪 3D 交互、明度切片、指标卡化。
2. **工艺库功能补全** —— 编辑/替换 ICC/批量上传/搜索筛选/聚合指标接口。
3. **交互细节标准化** —— 模态可达性、骨架屏、错误态、联动闭环、移动端适配。

**版本决策记录**：
- 3D 采用「两步走」：V0.3 用纯 Canvas 2D 斜投影伪 3D（零依赖），组件 API 预留渲染器注册表，
  V0.4 替换 three.js 真 3D 渲染层（凸包网格 + 光照）。
- lcms2 浮点精度升级（打破 ΔE≈0.5 量化地板）放 V0.4，本轮仅立项。

## 4. 关键技术契约

### 4.1 gamut API 数据契约（升级后）

```
GET /api/processes/{pid}/gamut?levels=N
{
  xy_points: [[x,y]...],        // 现有
  lab_points: [[L,a,b]...],     // 新增：与 xy_points 等长对齐
  hull: [i0,i1,...],            // 新增：xy 平面凸包顶点索引（闭合顺序）
  volume, L_range, a_range, b_range, sampled,   // 现有
  coverage_srgb: 0.62           // 新增：采样点落在 sRGB 三角内的比例
}
```

凸包实现：numpy Andrew 单调链（不引入 scipy），先滤除 Y≈0 暗点（黑点在 xy 图聚在原点破坏凸包）。

### 4.2 gamut-view 组件契约（V0.4 three.js 预留）

```
createGamutView(el, { getData, mode, theme })
  → { setMode('2d'|'3d'), setSlice(l|null), setRotation({theta,phi}),
      onHover(cb), redraw(), destroy() }
```

- DOM 契约恒定：`.gamut-stage > canvas.gamut-canvas + .gamut-hud(.gamut-tip) + .gamut-controls`
- 渲染器注册表 `registerRenderer(name, impl)`；V0.3 注册 `'canvas2d'`，V0.4 注册 `'three'`
  时视图状态、tooltip、切片滑块、事件层全部复用。

### 4.3 伪 3D 投影参数

- 默认 θ=35°（方位角）、φ=25°（倾角）；拖拽 `Δθ = dx·0.5°/px`，φ ∈ [10°, 80°]
- 基向量：`right=(cosθ,0,−sinθ)`、`up=(−sinφ·sinθ, cosφ, −sinφ·cosθ)`、`eye=(cosφ·sinθ, sinφ, cosφ·cosθ)`
- screen = p·right / p·up；深度 = p·eye；painter 排序由远及近；点尺寸按深度 1.1→2.4px
- 颜色取 Lab 真彩（`labToCss`，D50→D65 Bradford 适应复用 `labToHex` 管线），明暗主题不变
- L\* 切片：`|L−s|≤6` 全饱和，其余 alpha 0.10；纯前端过滤无请求

### 4.4 图例色值统一（唯一真源）

| 元素 | 令牌 | 亮色 | 暗色 |
|---|---|---|---|
| sRGB 多边形/图例 dot | `--accent` | `#007aff` | `#0a84ff` |
| 工艺凸包/迷你图 | `--indigo` | `#5856d6` | `#5e5ce6` |
| 工艺采样点云 | L\* 真彩 | 数据色 | 数据色 |
| 光谱轨迹/紫线 | locus.hex / `#c95cd6` | 固定 | 固定 |
| 3D 网格/轴 | `--separator` / `--label-3` | — | — |
| 配方通道 Y | `--yellow` | `#ffcc00` | `#ffcc00` |

canvas 侧经 `resolveToken(name)`（getComputedStyle）取值；HTML 侧用 `var()`；两主题同步。

## 5. 测试与验收策略

1. **测试资产去平台化**：sRGB 用 `create_srgb_profile()` 运行时生成；CMYK/GRAY 入库
   `tests/fixtures/icc/`（littlecms testbed，MIT 许可，附 THIRD-PARTY-LICENSES.md）；
   `COLORFORGE_DATA_DIR` 环境变量注入实现测试隔离。
2. **API 层**：`tests/test_api_{processes,recipes,files,static}.py`，TestClient 覆盖 CRUD/
   级联删除/缓存 bug 回归/GRAY/批量上限/verify 闭环/预检转换/静态资源。
3. **精度基线门禁**：`tests/test_precision_baseline.py` + `tests/baselines/precision_baseline.json`，
   硬门禁 ΔE<3，回归门禁 ΔE≤基线+0.15 且配方分量漂移≤2%，标记 `precision`。
4. **前端冒烟**：`node --check` 语法 + TestClient 静态资源断言；人工视觉验收清单（下表）。
5. **性能基准**（`slow` 标记）：predict 20 目标中位 ≤10s；gamut levels=10 采样 ≤8s。
