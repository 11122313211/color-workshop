# V0.4 实施规划 —— 真 3D 色域 + 精度升级 + 监控闭环

> 版本：V0.4（规划基线 V0.3） · 定稿日期 2026-11-15
> 立项来源：`docs/V0.3-下一阶段规划.md` §6 展望 + P2 backlog，六项全量实施，分四个里程碑。

## 1. 版本定位

V0.3 完成了 ICC 模块「专业好看」与工程底座。V0.4 聚焦两件事：

1. **把精度与智能做深** —— 反查引擎打破 8-bit 量化地板（多线性插值精搜层），
   闭环从「单次补偿」升级为「工艺级累积学习」（补偿模型沉淀）。
2. **把色域可视化和质量监控做实** —— three.js 真 3D（表面网格 + 光照 + 深度交互）、
   ΔE 漂移监控面板、多工艺色域对比运算、PDF 印前预检。

**版本决策记录**（环境探测后修正）：
- 原立项「ctypes 直调 lcms2 浮点 API」在本机不可行：无 lcms2.dll、PyPI 无 `lcms2` 包、
  `pylcms2` 无 cp314 轮子（本机 Python 3.14）、无 gcc/cmake 自编译条件。
  → 改为**纯 numpy 多线性插值精搜层**达成同一目标（打破量化地板），零新依赖、跨平台；
  ctypes 路线记入 V0.5。
- three.js 采用 vendored ESM（npm tarball 下载 + sha512 校验，MIT）+ 自研迷你 orbit，
  不引入 importmap/构建步骤，WebGL 不可用时静默回退 V0.3 伪 3D。
- pypdf/pypdfium2 已在环境中但未声明 → requirements.txt 补声明；scipy 继续不引入。

## 3. 关键技术契约

### 3.1 插值精搜层（recipe.py）

```
lut_key = sha:LUT_LEVELS:channels（不变）
_interps[lut_key] = interp(pts, labs, levels, channels)   # 多线性插值 f(d)→Lab 连续
精搜：step 1/(levels-1)/4 → 对半细化至 1/2048，ΔE 目标为 f(d)，REFINE_FLOOR = 0.10
守门：候选经真实 forward() 单点验证，严格更优才接受；predicted_lab/delta_e 恒为真实值
返回：+refine_predictions；粗搜 DE_FLOOR=0.5 语义不变
```

误差模型：8-bit LUT 格点携带 ±0.4 量化噪声，多线性插值即对噪声做低通（σ 降约 √(Σw²)），
同时目标函数连续化——能分辨 8-bit 评价下无法区分的更优配方；真实 forward 兜底防止插值偏差。

### 3.2 补偿模型（compensation.py）

```
data/compensations.json  key=process_id
{ icc_sha256, n, bias_device: [C], history: [≤10 条 {ts, delta_device, delta_e_before/after}], updated_at }
累积：verify 且 improved → delta = corrected_recipe − recipe（/100 归一），EMA α=0.35，逐通道截幅 ±0.15
应用：predict 传入 device_bias 作用于 3 个种子（clip）；sha 匹配且 n≥2 才生效
失效：icc_sha256 不匹配即重置；DELETE /api/processes/{pid}/compensation 手动重置
```

### 3.3 three 渲染器接线（gamut-view.js / gamut-three.js）

- 渲染查找从「创建时一次性捕获」改为 schedule() 内 mode-aware：
  `3d → 'three'（已注册且 WebGL 可用）否则 'canvas2d'`
- three 渲染 WebGLRenderer 复用 `canvas.gamut-canvas`；相机方向 = 现有 `basis(θ,φ).eye`，
  拖拽/双击/切片事件层零改动
- 表面网格：Lab 空间凸包包络（scipy Qhull，服务端输出三角索引 `data.surface.triangles`），
  逐顶点 `labToLinearRgb` 着色（components.js 抽出导出），MeshLambert + ambient/directional，
  opacity≈0.42 DoubleSide、depthWrite=false；L\* 切片开启时外壳淡化至 0.08 聚焦切片层。
  （实施修正：原「设备立方体外亮面四边形」方案对 CMYK 不成立——4 维立方体外亮面是 3 维
  薄片，映像为体积而非表面；凸包即经典色域包络观感，非凸等值面记 V0.5）
- 点云 ShaderMaterial：attribute aLab/顶点色 + uniform uSlice/uSliceOn，切片零重建
- `static/vendor/three/`：three.module.js（+ 依 tarball 实际结构的 three.core.js）+ 上游 MIT LICENSE

### 3.4 stats / compare / pdf API 形状

```
GET /api/recipes/stats?process_id=
{ total, converged_rate, mean_de, p95_de,
  series: [{id, created_at, delta_e, converged, process_id, process_name, label, tolerance}],  # 时间升序
  processes: [{process_id, process_name, n, mean_de, p95_de, pass_rate, drift}],
  flags: [{process_id, process_name, message, severity}] }

GET /api/processes/{pid}/gamut/compare?other={oid}&levels=6
{ a, b,                      # 两份完整 gamut 载荷
  a_only: [i...], b_only: [i...], both: [i...],   # A 点对 B 凸包的归属（索引入 a.lab_points）
  inter_poly: [[x,y]...], area_a, area_b, area_inter }

POST /api/files/preflight  （PDF 分支新增字段）
{ ..., pages, pdf: {page_sizes_mm, images:[{page,px,colorspace,icc?}], spot_colors,
                    has_output_intent, fonts, transparency}, thumbnail_b64 }
```

## 4. 测试与验收策略

1. 每里程碑 `python -m pytest tests/ -q` 全绿（50 → 62+ 用例）：插值器单元（线性零误差）、
   精搜不劣化对照、补偿累积/失效/重置、stats 对账与漂移触发、compare 手算凸形断言、
   PDF 双 fixture（Pillow 运行时生成 RGB/CMYK 版，不引入二进制资产）、监控路由静态。
2. e2e_http.py 扩展（stats/compare/compensation/PDF/版本号）。
3. 视觉验收（in-app browser + Edge headless `--use-angle=swiftshader`；headless WebGL 不可用
   则验证回退路径）：three.js 3D 亮/暗/网格/切片/旋转复位、监控页、对比模态、PDF 预检卡、375px。
4. 收尾：Mimosa 深度扫描（0 发现口径）→ `git tag v0.4.0` → push GitHub。
