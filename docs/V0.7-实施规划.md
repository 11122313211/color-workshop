# V0.7 实施规划 —— 印刷校准闭环：从校准样张到墨量修正

> 版本目标：让「生成校准版 → 打印 → 色差仪测量 → 双基准差距报告 → 一键应用墨量调整 → 导出校正曲线/特性数据」在项目内形成完整闭环。V0.6 交付的是测量数据的**诊断**（分级→指标→规则结论），V0.7 交付的是印刷条件的**校准**（实测对齐预期→修正设备→复测收敛）。

## 1. 背景

用户流程诉求：手头有色差仪（Lab 口径）与印刷输出条件，希望：

1. 生成**可直接打印**的校准测试版（编号色块，方便逐块测量）；
2. 打印后用色差仪测量 C100/Y100/K100 等；
3. 系统算出**差距应该有多少**——与工艺 ICC 预测值比（模型 vs 印刷机）、与 ISO 12647-2 行业参考值比（绝对达标）；
4. 一键把逐通道墨量调整写入补偿模型（配方预测立即联动），并导出校正曲线与特性数据（供 ArgyllCMS / i1Profiler 等专业软件生成正式 ICC）。

与既有能力的关系：

| 环节 | 现状 | V0.7 |
|---|---|---|
| 测试版 | 验证样张（梯尺+星标，无编号、无预期值） | 新增专用校准版（编号矩阵 + 参考表导出），验证样张保留 |
| 测量导入 | cgats.py 双格式 + verified 分级 | 直接复用 |
| 差距对比 | QC 指标 vs 密度口径（V0.6）；配方单点 verify | 新增逐 patch 双基准批量对比报告 |
| 修正落地 | 补偿模型 per-channel bias（配方 verify 单点沉淀） | 校准报告一键写入（整版依据，一次到位） |
| ICC 生成 | — | 项目内不造 ICC（lcms 只做变换不做拟合）；导出曲线 + 特性数据交给专业软件 |

## 2. 数据政策（硬约束，沿袭 V0.6）

- 全部测试/e2e/视觉验收数据为**合成**，不引用任何非公开真实测量值；
- 行业常量以 `#:` 注释标注出处（见 §3）；
- 文档隐私筛查 0-hit（不得包含个人姓名、编号、机构、邮箱或本地路径等身份敏感信息）。

## 3. 行业常量与出处

### 3.1 ISO 12647-2:2013 固体色 Lab 参考值（涂布纸 type 1/2，D50、2°）

| 色块 | L* | a* | b* | 固体允差 ΔE00 |
|---|---|---|---|---|
| C | 55 | −37 | −50 | ≤3.5 |
| M | 48 | 74 | −3 | ≤3.5 |
| Y | 89 | −5 | 93 | ≤3.5 |
| K | 16 | 0 | 0 | ≤5.0 |
| CMY | 23 | 0 | 0 | —（参考列） |

出处：ISO 12647-2:2013 原件（iteh.ai 预览件）；数值与 Print Codex《Measurements & Standards》指南交叉一致。**非涂布纸（type 4/5）**：公开网页来源数值互相矛盾（黄版 b* 符号不一致），按数据政策**不收录**——非涂布工艺的 iso 列返回 null 并提示「以工艺 ICC 预测值为基准」。

### 3.2 ISO 12647-7:2016 控制条精神（汇总判定）

- 单体 ΔE00 max ≤ 5.0；平均 ΔE00 ≤ 2.5（2016 版全面改用 ΔE00 口径，Fogra 2017 说明）；
- 梯级取 100/75/50/25/10（IDEAlliance ISO 12647-7 Control Wedge 布局）。

### 3.3 ISO 10128:2009 校正方法学

标准给出三种印刷校正方法：校正曲线法、设备校准法、DeviceLink 法。V0.7 落地**校正曲线法**：

- **曲线**：Lab 口径有效网点反演——实测色块 Lab 反查 ICC 正向轴上等效设备值 e(t)（即「设备现在印 t，相当于 ICC 里的 e(t)」），校正曲线 t→e⁻¹(t)（发送 e⁻¹(t) 使实际输出落在 ICC 预期上）；与 ISO 10128 的 TVI 差修正同构，只是修正量来自 Lab 反演而非密度 TVI 差（纯色差仪无密度通道也可用）；
- **实地**：模型误差补偿 p' = 2·预期 − 实测（与 recipe.run_verification 同式）后沿单色轴反查修正设备值 → 逐通道墨量建议（写入补偿模型 bias_device）。

### 3.4 判定阈值汇总

| 判定 | 阈值 | 出处 |
|---|---|---|
| 固体 C/M/Y vs ISO | ΔE00 ≤ 3.5 | ISO 12647-2:2013 |
| 固体 K vs ISO | ΔE00 ≤ 5.0 | ISO 12647-2:2013 |
| 其他色块 vs ISO/无 ISO 列 | ΔE00 ≤ 5.0 | ISO 12647-7:2016 精神 |
| 整版汇总 | max ≤ 5.0 且 avg ≤ 2.5 | ISO 12647-7:2016 |
| overall 状态 | 任一固体超 ISO 允差或 max>5 → 需校准；avg>2.5 → 建议校准；否则达标 | 组合口径 |

## 5. 报告与修正算法

### 5.1 calibration_report(工艺, 会话)

1. 收集 verified 记录，按标签配对（P 编号或标签归一），跨记录求 Lab 均值（n 记入行）；
2. 每 patch：`measured_lab`、`expected_lab`（ICC 批量正查）、`iso_ref_lab`（涂布固体才有）、ΔE00 双基准 + `delta_e_components`（dL/da/db/dC/dh）；
3. 汇总：max/avg ΔE00（ISO 口径）、固体达标表、overall 状态（§3.4）；
4. `ink_suggestions`：C/M/Y/K 各由其 100% 固体行推出（单色轴反查，见 §3.3）；
5. `curves`：每通道 [(0,0), (10,e⁻¹(10)) ... (75,e⁻¹(75)), (100,100)]——固体端点固定不曲（固体交给墨量建议）；
6. 导出文本（服务端组装，前端 downloadDataUri）：
   - `curves_csv`：通道,t_nominal,t_corrected；
   - `characterization_cgats`：设备名义值 + 实测 Lab（当前印刷条件的真实特性数据 → 外部建 ICC）；
   - `corrected_cgats`：校正后设备值 + 预期 Lab（「校准后设备」一阶近似特性数据，标注需复测验证）。

### 5.2 apply（写入补偿模型）

`CompensationStore.apply_calibration(pid, icc_sha256, delta_device)`：bias = clip(现 bias + 建议, ±0.15)（**直接叠加**，区别于 EMA——校准是用户显式确认的动作），history 追加 `{ts, source: "calibration", delta_device}`，`n = max(n, MIN_N)`（显式校准视为可信样本，越过 MIN_N=2 应用门槛）。ICC sha 不匹配时按既有补偿语义**重置后写入**（新 ICC 的墨量行为可能完全不同，旧偏置不可沿用）。

### 5.3 边界与降级

- 非 CMYK 工艺 → 端点 422（校准版按四色印刷设计）；
- 会话未绑定工艺 → 422；工艺 ICC 与当前存储不符 → 409；
- verified 记录中命中 <4 个 patch → overall="n/a"，报告说明「未按校准版测量」；
- 实地反查 achievable ΔE 过大（>10）→ 建议标注「超出墨量可修正范围，检查印刷条件/ICC」。
