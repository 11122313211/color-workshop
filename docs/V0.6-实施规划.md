# V0.6 实施规划 —— 闭环后半环：从分级数据走向诊断与修正

## 1. 背景与动机

V0.5 交付了可信测量闭环的**前半环**：目标（工艺 ICC / 配方预测）→ 样张（双点重复布局）→ 测量（CGATS/TSV 导入 + 会话登记）→ 五规则可靠性分级（verified / warning / rejected）→ 分级数据流向（QC 指标、ΔE 分量、补偿门禁只消费 verified）。

对实验方法论的复盘得出结论：闭环的**后半环**在产品中缺位，而这正是印刷质量检测实验的核心方法论：

| 后半环环节 | 方法论内容 | V0.5 现状 |
|---|---|---|
| ⑥ 量化指标 | 相对反差 K、油墨叠印率 T、灰平衡 a*/b* 偏移、实地多点均匀性 | 只有 GATF 四指标 + TVI |
| ⑦ 诊断 | 指标→成因映射（TVI 偏大→压力/墨量；叠印不良→色序/粘度；灰偏→CMY 配比；星标形态→网点变形方向） | 只有 ΔE 分量展示，无结论输出 |
| ⑧ 过程修正 | 纠正措施落在工艺参数（压力、墨量、速度、色序） | 补偿沉淀只覆盖配方级 |
| ⑨ 复测监控 | 「定期抽检 75% 网点密度与反差率，监控暗调层次」 | 会话一次性，无对比无趋势 |
| ⑩ 主观评价 | GB/T 34053 精神：标准环境、多评价人独立 5 级打分、均值±标准差、一致性校验 | 无 |

V0.6 主题：**把分级数据推向诊断与工艺修正**——指标补全 → 规则型诊断引擎 → 会话趋势对比 → 主观评价检查单。

### 数据政策（硬约束）

- **不使用课程真实测量数据**。所有测试 / e2e / 视觉验收数据均为合成；课程材料只提炼方法论（公式、协议、判读逻辑）。
- 量化常量（TVI 目标、允差、K 值下限、叠印率合格线）**全部来自行业标准检索**，每条标注出处。
- 文档隐私筛查：成品文档 0 命中课程人员身份信息（姓名 / 学号 / 院校 / 指导教师）。

## 2. 方法论来源（仅方法论，不含数据）

### 2.1 相对反差 K（print contrast）

- 定义：`K = (Ds − D75) / Ds`，Ds 为实地密度，D75 为 75% 网点密度；取值 0~1。
- 含义：K 越大，暗调层次区分能力越强；K 下降提示暗调网点并级、糊版。
- 方法论要点：75% 网点是暗调层次的关键控制点——测试样张必须包含 75% 梯级（V0.5 样张步进 10 缺 75%，本版补齐）。
- 行业允差：ΔK ±10%。

### 2.2 油墨叠印率 T（trapping）

- 定义：`T = (D₁₊₂ − D₁) / D₂ × 100%`——叠印总密度减去先印色密度（同一滤色通道），除以后印色单色密度。
- 通道取法：按标准色序 K→C→M→Y（高粘度先印、透明度高的黄最后印），第二印色的补色滤色片读数：R(M+Y) 与 G(C+Y) 用黄滤色通道，B(C+M) 用品红滤色通道。
- 行业合格线：T ≥ 60% 为最低可接受；低于合格线的配对按排名输出，给出色序 / 油墨匹配 / 干燥速度修正方向。

### 2.3 灰平衡偏移

- 方法论：CMY 三色叠印的中性灰块，以 a*、b* 相对零点的偏移量评价偏色；偏移量越小灰平衡越准。
- 方向诊断：a*>0 偏红 / a*<0 偏绿；b*>0 偏黄 / b*<0 偏蓝；据此给 CMY 配比修正方向。
- 行业依据：GB/T 17934.2-2021（对应 ISO 12647-2）灰平衡偏差以 ΔE 衡量约 ±0.9；本版按分量控制 |a*|、|b*| ≤ 1.0。

### 2.4 实地均匀性

- 方法论：同一实地色块多点（或多张）测量，以密度离散程度（标准差 / 变异系数）判断墨层均匀性——数据波动越小墨层越一致。
- 产品落点：复测模式下同标签 ≥2 条 verified 记录，统计主滤色通道密度的 mean / std / CV。

### 2.5 主观评价协议（GB/T 34053 精神）

- 标准观测环境（D65 光源、无杂光、规定观测距离）、多名评价人独立打分、统一 5 级尺度。
- 统计方法：每指标算术平均 + 标准差；标准差反映评价人打分一致性，离散过大提示评价尺度失稳。
- 产品落点：三套检查单模板（书刊 / 纸包装 / 塑料包装），指标组覆盖色彩、阶调、清晰度、墨色、成型维度。

### 2.6 目视诊断（星标 / 细线 / 套准）

- 星标判读（GATF 口径，约 35:1 形变放大）：中心小圆白点完整=正常；中心均匀黑化扩大=网点增大；方向性楔形变形=滑版/条杠；偏方向非对称变黑=重影；中心白点扩大=网点收缩。
- 细线组：正 / 反白细线（0.01-0.6pt）检验极细网点还原，断线 / 反白堵塞为不合格特征。
- 套准标记：圆 / 三角撞色叠印，边缘错位量化套印误差。
- 产品落点：样张第二页「目视诊断区」，页脚印判读口诀。

## 3. 行业标准量化依据表

| 常量 | 值 | 出处 |
|---|---|---|
| TVI 中间调控制点 | 50%（ISO 12647-2:2013；2004 版为 40%，40% 仍作参考点） | ISO 12647-2:2013 |
| TVI 目标（CMY 涂布纸，中间调） | 16% | ISO 12647-2:2013 |
| TVI 中间调允差 | ±3% | ISO 12647-2 行业通行 |
| TVI 第二控制点 | 80% 处 12% | ISO 12647-2:2013 |
| 实地色 CIELAB 允差 | CMY ΔE00 ≤ 3.5，K ≤ 5 | ISO 12647-2 |
| 反差率 K 允差 | ΔK ±10% | 行业通行 |
| 反差率 K 预警下限 | 0.40 | 胶印暗调控制经验值 |
| 叠印率合格线 | ≥ 60%（最低可接受） | 行业通行 |
| 灰平衡偏移 | \|a*\|、\|b*\| ≤ 1.0 | GB/T 17934.2 精神（ΔE≈±0.9） |
| 均匀性预警 | 实地密度 CV > 5% | 多点离散度方法通行阈值 |
| 星标形变放大率 | 约 35:1 | GATF 测试版用户指南 |

> 注：TVI 目标曲线随纸张类型与加网线数变化（非涂布纸 a≈19-23），产品常量取涂布纸胶印基准值并在文案中注明「以工艺校准曲线为准」。

## 4. 诊断规则表（规则 → 证据 → 成因 → 建议 → 依据）

| # | 规则 | 触发条件 | 证据 | 成因 | 建议动作 | 依据 |
|---|---|---|---|---|---|---|
| R1 | TVI 中间调偏差 | \|TVI50 − 16%\| > 3% | 各色 TVI50 实测值 | 偏高：压力过大/墨量过多/纸张吸墨过强；偏低：转移不足 | 偏高→降压力、减墨量；偏低→核查压力与墨量匹配 | ISO 12647-2:2013 |
| R2 | 暗调反差不足 | K < 0.40 | 各色 K 值与 Ds/D75 | 暗调网点扩大并级 | 降整机压力、减各色组供墨，重点核查暗调 | 行业 K 值控制 |
| R3 | 反差一致性 | 四色 K 极差 > 0.10（相对允差 ±10%） | K 极差 | 各色组墨量/压力不均 | 对偏差最大的色组单独校正 | ΔK±10% |
| R4 | 叠印不良 | T < 60% | 配对 T 排名 | 后印色附着不良：粘度/表面张力失配、干燥过快 | 调整油墨配比、放缓速度、延长层间干燥 | 行业 60% 合格线 |
| R5 | 灰平衡偏色 | \|a*\|>1.0 或 \|b*\|>1.0 | da/db 数值与方向 | CMY 配比偏离该纸张/墨组的灰平衡点 | 按偏色方向给 CMY 配比修正方向 | GB/T 17934.2 |
| R6 | 墨层不均 | 实地密度 CV > 5% | n / std / CV | 供墨不均、纸张吸墨不一致 | 检查墨辊匀墨与纸张批次 | 多点离散度方法 |
| R7 | 数据充分性 | 缺 75% 梯级 / 叠印块 / 灰块 / 复测对 | 缺失清单 | 样张或测量模式不完整 | 指引生成 V0.6 样张、启用复测模式 | 方法闭环 |
| R8 | 油墨色偏解读 | 色相误差 > 0.35 或灰度 > 0.30 | GATF 三指标 | 原生油墨色偏/叠印脏化 | info 级解读，提示对色 | GATF 口径 |

severity 分级：`ok`（正常）/ `info`（解读与指引）/ `warn`（需关注）/ `err`（超出行业合格线）。
